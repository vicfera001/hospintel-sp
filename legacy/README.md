# Protótipo inicial

`transform_sih_sus_5_municipios.mjs` é o script original utilizado na primeira
exploração do arquivo DATASUS. Ele seleciona cinco municípios — Guarulhos,
Osasco, Santo André, São Bernardo do Campo e São Paulo — e produz 60 registros.

O script foi preservado para documentar a evolução do projeto, mas não gera o
dataset completo importado no Oracle. Para reproduzir as 3.924 linhas, utilize
`src/transformar_datasus.py`.
