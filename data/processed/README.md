# Dados processados

`internacoes_sp_2025_long.csv` é o arquivo UTF-8 em formato longo importado para
o Oracle Autonomous Database. Cada linha representa um município em um mês.

Colunas:

- `codigo_municipio`: identificador municipal de seis dígitos;
- `municipio`: nome normalizado sem acentos;
- `mes_referencia`: primeiro dia do mês em `YYYY-MM-DD`;
- `internacoes`: quantidade de internações, em número inteiro não negativo.
